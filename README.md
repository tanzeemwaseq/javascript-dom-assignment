# JavaScript DOM Assignment

This repository contains 14 mini projects built as part of a JavaScript and DOM assignment. Each project focuses on practicing fundamental JavaScript concepts, DOM manipulation, event handling, timers, forms, and interactive user interfaces.

## Projects

1. Counter App
2. Background Color Changer
3. Character Counter
4. Age Calculator
5. Random Quote Generator
6. Digital Clock
7. Password Generator
8. Gradient Background Generator
9. Stopwatch
10. Number Guessing Game
11. Student Result Calculator
12. Simple Calculator
13. Show / Hide Password
14. Live Text Preview

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM API


## Purpose

This repository was created to strengthen my understanding of JavaScript fundamentals and DOM manipulation through hands-on practice with small interactive projects.
